面向初学者的 18 章教程

Javalin 社交博客实战

这套教程改编自 O'Reilly 的经典教材《Flask Web Development》（第 2 版，Miguel Grinberg 著）。 原书用 Python 的 Flask 一步步搭出一个叫 Flasky 的社交博客； 这里保留原书全部的知识骨架和章节顺序 —— 路由、模板、表单、数据库、邮件、认证、权限、分页、关注、评论、API、测试、性能、部署 —— 但把所有代码换成了 Javalin 和它的 Java 生态：JTE 模板、Hibernate ORM、Flyway、JUnit 5……

为什么要“换框架重学一遍”？

原书讲的东西 —— HTTP 请求怎么变成响应、表单为什么要重定向、密码为什么不能明文存、 会话 Cookie 为什么要签名、REST API 为什么要无状态 —— 和语言、框架都没有关系。 Flask 只是承载这些知识的一个容器。

Javalin 是一个很“轻”的 Java / Kotlin Web 框架：核心只有一个 jar， 没有注解扫描、没有 IoC 容器、没有自动配置的魔法。 你写的每一行代码都在你能看见的地方执行 —— 这一点和 Flask 的气质几乎一模一样。 正因为它薄，它特别适合用来学习 Web 开发本身： 你不会把框架的约定误当成 Web 的规律。

🧩

小

核心只依赖 Jetty 和 SLF4J。整个框架的源码一个周末能读完。

🔢

类型安全

JTE 模板在编译期检查：模板里写错字段名，mvn compile 就报错。

⚡

没有魔法

没有注解扫描、没有依赖注入容器。路由是你亲手注册的，调用栈是直的。

📦

一个 JAR 上线

mvn package 产出可执行 JAR，java -jar 就是生产环境。

这套教程写给谁

  • 会一点 Java，但没写过 Web 服务端的人。每一章都从“为什么需要这个东西”讲起，而不是直接甩 API。
  • 用过 Spring Boot，但觉得“不知道它背后干了什么”的人。 Javalin 把 Spring 自动配置替你做掉的事全部摊在明面上：会话是怎么存的、拦截器什么时候跑、事务边界在哪里。 看懂这些，再回去用 Spring 会完全不一样。
  • 读过原书（或 Flask 系列教程），想把这套知识迁到 Java 技术栈的人。 大量章节里有「Flask 这样写 / Javalin 这样写」的左右对照卡片。
ⓘ 需要什么前置知识

会写类、方法、接口、List/Map，知道 lambda x -> x + 1 是什么就够了。 不需要会 Spring、不需要会 Maven（第 1 章从零讲）、不需要懂 SQL（第 5 章从零讲）。 命令行只需要会 cd 和敲命令。

☀ 一个关键差异，提前说

Flask 里 request、session、current_user 是看起来像全局变量的东西 （底层是线程局部存储 + 上下文栈）。Javalin 不玩这一套： 每个处理器都显式接收一个 Context ctx 参数，请求、响应、会话全从它上面取。

一开始你会觉得“怎么到处都要传 ctx”，但很快会发现这让调用关系变得特别清楚 —— 没有“为什么这里报 working outside of request context”这种困惑。

贯穿全书的例子：Javalinky

和原书一样，我们会一路建设同一个应用：Javalinky，一个带用户系统的社交博客。 从第 2 章的一行 “Hello World” 开始，到第 17 章部署上线， 中途它会长出模板、表单、数据库、邮件、登录、权限、头像、Markdown 编辑器、关注关系、评论、REST API……

怎么用这套教程

  • 按顺序读。后面的章节会用到前面建立的项目。第 1 章是环境准备，急的话可以扫一眼就跳到第 2 章开始动手。
  • 亲手敲代码。每章末尾都有「动手练习」。看懂和写出来之间的差距，比你想象的大。
  • 遇到 对照 卡片时留意左边。左边是 Flask / Python 的写法，右边是 Javalin / Java 的写法。如果你没用过 Flask，忽略左边即可。
  • 看到虚线框的「原书检查点」，那是告诉你这一节对应原书 GitHub 仓库的哪个标签（例如 git checkout 5b），方便你对着原版 Python 代码比较。

配套代码：一章一个标签

这套教程有一份真正跑起来过的配套代码，就在同一个仓库的 javalinky/ 目录里。它不是“示意代码” —— 每一章结束时的状态都打了标签， 并且逐章做过编译、单元/集成测试、以及真实启动访问的验证： 

git clone <这个仓库>
cd javalinky

git checkout jv-ch05                              # 想看第 5 章就 checkout 第 5 章
mvn -q compile exec:exec@cli -Dcli.args="deploy"  # 建库 + 灌角色
mvn -q compile exec:exec                          # 启动，打开 http://localhost:7070

标签从 jv-ch01 到 jv-ch17，master 上是最终形态。 每章页面开头都有一个“本章代码”卡片，写着对应的标签。 怎么造假数据、怎么收测试邮件、怎么打包部署，见 javalinky/README.md。

🔎 代码和文字对不上的时候，信代码

教程是先写的，代码是之后真正跑起来的。这个过程里发现了几十处需要修正的地方 —— 框架 API 的实际签名（比如 Validator.allowNullable() 在 Javalin 7 已经改成 getOrNull()）、JTE 不允许的写法、少写的依赖和文件、以及必须调整的顺序。 每一条都记在 javalinky/TUTORIAL-DIFFS.md 里，也顺便是一份 “真实项目里会踩到什么坑”的清单，值得单独读一遍。

⚠ 关于版本号

教程里的依赖版本（Javalin 7.2.3、Hibernate 7.4、JTE 3.2.4……）是写作时的稳定版。 Java 生态升级很快，你照抄这些版本一定能跑通；想用新版本的话，在项目目录下执行 mvn versions:display-dependency-updates 就能看到有哪些更新。

💡 一句话总结

如果你只记住一件事：Javalin 应用就是“一张路由表 + 一串 ctx -> {} 处理器”， 过滤器（before / after）是包在处理器外面的一层层洋葱皮。 这套教程剩下的 18 章，都是在解释这句话的各种展开。
